PREPARE YOUR STUDIO / INSTALLATION

One skill.
Your way to create.

Editing and visual scenes together. A portable skill for Codex and Claude Code, running on your computer.

01

Open the project folder

Download the repository and open a terminal in the folder containing install.py. Prepare Python 3.9+ for the launcher, uv, FFmpeg/ffprobe, Node.js 22.13+ or 24+, npx, and your AI agent. The installer prepares engine dependencies with a supported Python version. System tools must be available in your terminal.

02

Register the skill

The installer shares one package between both agents. To use just one, replace both with codex or claude.

python3 install.py --target both

Restart your agent after installation so it discovers the skill.

03

Check before editing

Run the diagnostic to inspect FFmpeg, Python dependencies, and scene files. A real render test is still needed. Resolve missing requirements before rendering.

python3 ~/.local/share/editonny/scripts/editonny.py doctor

To open this guide again:

python3 editonny.py guide
04

Make your first request

Use $editonny in Codex or /editonny in Claude Code. Specify your video folder and request a sample before the complete project.

PREFER ASKING YOUR AI?

Installation starts
with a request too.

Open the repository in your agent and send:

Install editonny from this repository for Codex and Claude Code using the project installer. Check dependencies with the diagnostic, preserve my settings, and explain missing requirements before downloading tools or using paid services.

Global skill or plugin?

The installer registers the skill across local projects: one copy at ~/.local/share/editonny, with links at ~/.agents/skills/editonny for Codex and ~/.claude/skills/editonny for Claude Code.

A plugin distributes the same skill through an agent manager. Choose one installation method to avoid duplicate entries.

Use just one agent

Run python3 install.py --target codex or python3 install.py --target claude. Start a new conversation and invoke the skill.

Registration is local. It does not automatically synchronize tools or files with cloud sessions or your phone.

Update safely

Run the new checkout installer again. It saves the previous installation under ~/.local/share/editonny-backups/ and preserves installation .env files.

Keep footage and projects outside the skill. Other personal files stay in the backup and are not merged. Check the update before removing any backup.

Remove agent registrations

Run python3 install.py --target both --uninstall. Add --dry-run to inspect destinations first.

This removes only the selected agent links. The shared package, settings, backups, videos, and projects remain.

Load as a Claude Code plugin

Use claude --plugin-dir "/path/to/editonny" to load this checkout for one session, then invoke /editonny:editonny. The standalone skill uses /editonny.

Avoid loading both forms at once. Video tools and the Python environment are still required.

What runs locally? What costs money?

This guide builds requests and browses examples and scenes. It does not upload or edit footage in the browser. The installed tools transcribe and render locally.

Your agent may require a subscription. Optional external generators may charge fees; the default request requires your authorization before using them or transmitting media.

How should I review a sample?

Listen for clipped words, check captions against the speech, and inspect framing throughout movement. Check volume, contrast, and whether effects clarify the explanation.

Do scenes support every format?

The catalog lists a source format, usually vertical. Your AI must adapt and verify other aspect ratios. A reference does not guarantee an identical render without review.
