# editonny product

Local video editing through conversation for people who record content and want to direct cuts, captions, audio, framing, and visual storytelling without operating every tool manually. First-party code and documentation are MIT licensed; third-party resources retain their own terms.

## Available workflow

1. The guide website (English, Brazilian Portuguese, and Spanish, chosen from the browser) offers 145 catalog scenes and 54 editable request examples and remembers the visitor's brief and theme in their browser.
2. The user takes a request, footage folder, and goal to Codex or Claude Code. The guide does not access or upload footage.
3. One portable skill inspects locally, presents the complete proposed settings and waits for a subsequent explicit reply before creating a workspace, transcribing fully or editing. Detailed prompts and broad autonomy still receive this initial confirmation.
4. Standard cleanup removes unnecessary pauses, audible breaths, mistakes, false starts, and redundancy. Complete words, natural expression, intentional pauses, meaning, originals, and the requested scope remain protected.
5. A representative 8–15 second sample is verified before completing the full video. Whether the agent waits for user approval follows the actual request.
6. Source appearance, geometry and timing are preserved by default. Color treatment, HDR/SDR conversion, crop, noise removal, music and extra visuals need explicit accepted choices; unsupported preservation routes block without silent downgrade.
7. Local work is organized under Downloads/editonny in independent revisions. Final files, requested subtitles and matching delivery manifests are published without overwriting previous exports. Remote execution requires a real accessible destination, not a claim that a remote Downloads is the user's computer.

English covers commands, schema, paths, prompts, and source content. The guide's interface and generated requests are localized for Brazilian Portuguese and Spanish, and the Portuguese and Spanish README translations are provided separately. Recordings and user-supplied text can remain in their original language. Speech lexicons are language data, not alternative product interfaces.

## Boundaries

The site is a guide and request builder on Vercel, not a browser editor, backend, upload service, account system, or hosted editing platform. Loading the skill does not install system tools or prove that transcription and rendering work.

New projects use a clean English contract; previous experimental formats and command aliases are unsupported. Personal projects are not rewritten automatically.

External generation, publication, media transmission, and charges require authorization. Remotion and manual desktop editors are optional integrations, not implemented timeline-export adapters. A sample render does not validate every scene, platform, or long-form video.
