## Confirmed editing and source appearance (1.1.0)

The original incident cannot be attributed to one exact source/export pair because no authorized pair was supplied. Controlled tests reproduced source-wide range/matrix changes: the old path forced limited-range BT.709/yuv420p and automatic HDR-to-SDR treatment. Fixtures contain independent stored YUV neutral/color samples, full/limited range, BT.601/BT.709, missing tags, PQ/HLG and 10/12-bit precision. VFR tests compare actual picture PTS, including a source whose nominal and average rates both report 24 FPS while one picture is delayed. Intake classifies observed demuxed PTS rather than assuming those two rate labels prove CFR. Packet-duration handling follows the [FFmpeg setts contract](https://ffmpeg.org/ffmpeg-bitstream-filters.html#setts). CIEDE2000 math is checked against the first three published [Sharma/Wu/Dalal reference pairs](https://www.ece.rochester.edu/~gsharma/ciede2000/ciede2000noteCRNA.pdf).

The explicit managed native conformance test (`EDITONNY_NATIVE_CONFORMANCE=1 uv run --locked --directory skills/editonny/engine python -m unittest discover -s ../../../tests/integration -p test_managed_native.py`) passed locally. An eight-second reviewed sample was followed by a nine-second full render from tagged SDR footage, retaining 360×640, 24 FPS and color tags. All 216 decoded picture timestamps matched the confirmed timeline within one output tick; sample approval remained valid across the full rebuild. At the measured corresponding midpoint outside generated caption bounds, deltaE00 median/p95 were 0.42677 (limits 1/2); encoded voice measured -14.02 LUFS and -9.70 dBTP. Vision recognized rendered captions with no layout findings. MP4, SRT, VTT and a matching delivery manifest published successfully; original bytes were unchanged. Exported frames were inspected. This is a synthetic color/voice signal fixture, not a natural-speech intelligibility or whole-timeline certification.

Runtime SDR comparison requires deltaE00 median ≤1, p95 ≤2 and p95 absolute linear luminance drift ≤1% reference white; HDR uses deltaEITP median ≤1, p95 ≤3 and sampled luminance tolerances (2% above 1 nit, 0.02 nit below; at most 5% sampled pixels outside tolerance). HLG assumes a 1000-nit zero-black display with system gamma 1.2. Measurements are sampled corresponding frames resized to 192 pixels wide, outside recorded time-dependent overlay bounds. Unknown transfer/primaries cannot receive a guessed PASS; metadata equality alone is insufficient. These runtime sample limits are distinct from universal per-pixel/per-frame fidelity, codec losslessness or HDR-display calibration.

Supported evidence covers SDR cut paths, full-range/BT.601 no-effect composition and an actual semi-transparent caption overlay, the named native SDR caption fixture and PQ/HLG/12-bit cut-only fixtures. Native HDR overlays, non-4:2:0 or higher-bit-depth FFmpeg overlays, Dolby dynamic metadata and non-square pixels remain blocked. HDR-to-SDR requires an accepted conversion and actual zscale/tonemap capability; this local FFmpeg lacks zscale. The HDR fixtures validate decoded signal behavior, not appearance on a calibrated HDR display. Explicit audio-track selection and multi-track source editing are blocked before acceptance rather than silently selecting track zero. Automatic abandoned-lock recovery is POSIX-only; Windows blocks before calling a liveness signal, following the documented [Python os.kill semantics](https://docs.python.org/3.12/library/os.html#os.kill). Long-form throughput, arbitrary phones/cameras, all scenes, playback software and remote filesystems remain unvalidated.

Behavioral pressure testing reproduced the old instructions starting work under autonomy without the complete summary and leaving the workspace root undefined. The updated skill requires a later explicit reply even for complete/autonomous prompts. Source, config, cut/timeline, engine and actual candidate hashes invalidate stale evidence; required blocked/not_checked checks prevent delivery. ## Reproduce and invalidate

```sh
npm ci --ignore-scripts
npm run build
npm run check
python3 editonny.py doctor
python3 editonny.py media status
npm run test:engine
npm run test:browser
npm run test:preview
npm run test:scenes
python3 scripts/smoke_engine.py
python3 scripts/package.py
```

`npm run test:browser` requires Playwright's Chromium (`npx playwright install chromium`); the preview and scene browser checks require agent-browser and its browser on PATH. Render checks require FFmpeg/ffprobe and may download the pinned package/browser on first use. Engine tests use the locked uv environment. Test installers with a temporary home; preserve footage, secrets, and personal installations. Inspect generated samples before removing task-owned `.work/` output.

Dependency, source, schema, asset, or interface changes invalidate the corresponding evidence and require focused verification. A structural audit or successful selected-scene test does not render every scene. Local checks do not prove Windows/Linux behavior, long-video performance, remote CI, client restart discovery, external generation, or real recording quality. Remote CI and publication must be verified separately after the push.
